# ExcaliPPT 安装说明

> 适用版本:0.1.2。安装后**完全离线可用**;联网时可获得新版本提示。

## 一、系统要求与选择安装包

**最低系统版本:**

- Windows:Windows 10 及以上(64 位)
- macOS:12 (Monterey) 及更高版本

| 安装包文件 | 适用系统 |
| --- | --- |
| `ExcaliPPT_0.1.2_Windows_x64.exe` | Windows 10 / 11(64 位) |
| `ExcaliPPT_0.1.2_macOS_arm64.dmg` | macOS 12 (Monterey) 及以上,**Apple Silicon(M1/M2/M3/M4)** |
| `ExcaliPPT_0.1.2_macOS_x64.dmg` | macOS 12 (Monterey) 及以上,**Intel 芯片** |

> 不确定 Mac 是哪种芯片:点按左上角 →「关于本机」—— 显示「芯片:Apple M…」→ 选 **arm64**;显示「处理器:Intel…」→ 选 **x64**。

## 二、Windows 安装

1. 下载 `.exe` 安装包,双击运行
2. 首次运行可能出现蓝色提示「Windows 已保护你的电脑」(SmartScreen): 点 **「更多信息」→「仍要运行」** ——应用未购买商业签名证书,属正常现象,仅首次出现
3. 安装为全自动(默认装入个人目录,无需选择路径),完成后自动启动

## 三、macOS 安装

1. 双击 `.dmg` 打开镜像
2. 将 **ExcaliPPT** 拖入 `Applications`(应用程序)文件夹
3. **首次打开**会被系统拦截一次(应用未公证,属正常现象,仅首次):
   1. 双击 ExcaliPPT,弹窗提示「无法验证开发者」或「无法打开」
   2. 打开 **系统设置 → 隐私与安全性**,向下滚动到「安全性」区域
   3. 看到「已阻止使用 ExcaliPPT」提示,点 **「仍要打开」**,再点「打开」
   - macOS 14 及更早版本:也可直接 **右键 App →「打开」→ 再点「打开」**
4. 之后从启动台 / 应用程序正常打开即可

> 若提示「文件已损坏」:多为下载不完整,请重新下载后再试。

## 四、检查更新

- **Windows(自动)**:联网状态下启动时及每 4 小时自动检查;有新版本会自动下载,弹窗提示重启即可完成安装
- **macOS(手动)**:菜单栏「**帮助 → 检查更新…**」,有新版本时给出下载链接,下载新 dmg 覆盖安装即可,已有画布数据不受影响

## 五、数据位置与卸载

- 画布数据保存在本机应用数据目录:
  - Windows:资源管理器地址栏输入 `%APPDATA%\excalippt-desktop` 回车即达
  - macOS:`~/资源库/Application Support/excalippt-desktop`
- 卸载:Windows 在「设置 → 应用」中卸载;macOS 将应用程序中的 ExcaliPPT 拖入废纸篓

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| macOS 打不开或闪退 | 大概率架构选错:M 系列芯片请用 `arm64` 包,Intel 请用 `x64` 包 |
| Windows 蓝色安全提示 | 「更多信息」→「仍要运行」(仅首次) |
| 「检查更新失败」 | 检查网络连接;或当前尚无新版本发布 |
